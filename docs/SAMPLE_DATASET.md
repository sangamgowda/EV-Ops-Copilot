# Sample dataset

The project ships with a **synthetic** dataset about one fictional
family of electric scooters, so it can be run, demonstrated and
evaluated without any real company data. It is generated by
`scripts/seed_synthetic_data.py` from `data/reference/ev_models.yaml`;
the same settings always produce the same data.

The default load (`python scripts/seed_synthetic_data.py --reset`) is
120 vehicles and 90 days of readings, ending on the day it is loaded.

## 2. What is stored

| Table | Rows | What one row is |
|---|---|---|
| `vehicles` | 120 | one scooter, **V-001 to V-120** (40 Volt 1, 48 Gen 2, 32 Ultra): city, firmware, features |
| `vehicle_telemetry` | ~1.5 million | one sensor reading: speed, current draw, battery voltage, charge, motor temperature, load, range estimate, cell health, charging power |
| `vehicle_baseline_specs` | 115 | the **normal** value per model and ride mode, which readings are compared against |
| `service_events` | ~360 | a workshop visit or customer complaint, often with an error code |
| `error_codes` | 16 | what each trouble code means and what to do, read from the service manual |
| `sales_transactions` | ~20,000 | one scooter sold: date, region, city, model, channel, price |
| `documents` | 12 | service bulletins, manuals, a help article and business reports (`data/documents/`) |

Regions: **south** (Bengaluru, Chennai, Hyderabad, Kochi, Mysuru,
Coimbatore), **west** (Pune, Mumbai, Goa), **north** (Delhi, Jaipur),
**east** (Kolkata, Bhubaneswar).

The data is deliberately a little messy, as real telemetry is: about
1% of readings are missing, a few are glitches (a current spike, a
temperature of −40), some vehicles go offline for a day or two, and a
handful never reported their odometer or city.

## 3. Test scenarios

A small number of vehicles carry a known fault, so that answers can be
checked against ground truth. Each has a cause visible in the data and
a document describing it, except the last, which no document explains.

| Scenario | Vehicles | What the data shows | Documented cause |
|---|---|---|---|
| Overload | V-042, V-007, V-029 | current draw ~38% above normal, load ~190 kg against a 150 kg rating, battery healthy | SB-114 |
| Firmware speed cap | V-012, V-055, V-088 | since firmware 3.2.0, speed in Sonic / Sonic X held near 42 km/h; other modes normal | SB-135, ERR_205 |
| Faulty charger | V-064, V-091 | charging power ~0.34 kW against 0.75 kW normal; riding normal | SB-140, ERR_303 |
| Battery wear | V-017, V-036 | cell health falling from 92% to 84% over the period; current draw normal | SB-121, ERR_402/403 |
| Unexplained consumption | V-023 | current draw ~30% above normal; load, battery and speed normal | none |

Sales follow a two-year curve across four regions. The Volt 1 Ultra
launched in the south ten weeks before the other regions, which shows
up as the south pulling ahead in the third quarter of 2026.

The measured numbers for each scenario are written to
`data/seed_manifest.json` every time the data is loaded. The questions
used to check behaviour on these scenarios, and what a correct answer
contains, are in the evaluation docs:
[`src/ops_copilot/evaluation/golden/README.md`](../src/ops_copilot/evaluation/golden/README.md).

## 4. Where it comes from

| Piece | File |
|---|---|
| Models, modes, prices, sales curve, regions | `data/reference/ev_models.yaml` |
| The generator, including the scenarios | `scripts/seed_synthetic_data.py` |
| Measured numbers per scenario | `data/seed_manifest.json` |
| Documents | `data/documents/` |
| A ready-made copy of the default data | `data/sample/` (compressed CSV) |

### Adding public web pages (optional)

Public articles can be added as extra documents. Pages are rendered in
a headless browser, names are replaced through a local find-and-replace
file, and the text is kept on your machine only: it is never
committed.

```bash
cd ui && node scripts/render-pages.mjs ../data/sources.yaml ../data/raw/pages && cd ..
python scripts/pages_to_documents.py data/raw/pages data/raw/docs \
    --sources data/sources.yaml --anonymize data/anonymize.local.yaml
python scripts/ingest_documents.py data/raw/docs
```

`data/sources.yaml` (the page list) and `data/anonymize.local.yaml`
(the replacements) are local, git-ignored files.
